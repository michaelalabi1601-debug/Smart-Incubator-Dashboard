# Smart Incubator: Advanced Analytics Dashboard
**Author:** Michael Alabi – Mechatronics Engineering (500L)

## Overview
An industrial-grade monitoring system for smart poultry incubation. 
This dashboard serves as the analytical layer of my 500-level project, 
transitioning from basic mobile monitoring to a high-fidelity 
HMI for data-driven agripreneurship.

## Tech Stack
- **Language:** Python 3.10
- **Framework:** Streamlit (UI/UX)
- **Data:** Pandas & Plotly (Analytics)
- **Protocol:** MQTT (Hardware Communication)

## Current Features
- [x] Simulation Mode for offline testing.
- [x] Real-time metric tracking for Temperature and Humidity.
- [ ] Live ESP32 Integration (In Progress).
